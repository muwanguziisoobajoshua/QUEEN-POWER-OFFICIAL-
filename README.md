# Queen Power Official — Music Website

A responsive static artist website designed for GitHub Pages.

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `assets/website-concept.png` — design concept/reference

## Publish on GitHub Pages
1. Create a GitHub repository, for example `queen-power-official`.
2. Upload all files and folders in this package.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your live website address.

## Important
Replace the placeholder artwork and platform URLs with Queen Power's real photos and official profiles.
For a custom domain, add the domain in **Settings → Pages → Custom domain**.
